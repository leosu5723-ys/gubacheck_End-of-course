# 股吧数据文件说明

这里保存10只股票的东方财富股吧数据，共 **1,098,973 条**。
时间区间：2025-10-03 00:00:00 至 2026-10-02 17:35:28，北京时间。

## 平时应该打开哪个文件夹？

直接做分析、统计或导入软件，打开 **十个股票的股吧数据**，使用其中的 `股票代码_365days.jsonl`。JSONL是UTF-8文本，一行一条JSON记录。

| 文件夹 | 用途 |
|---|---|
| 十个股票的股吧数据 | 最终整理数据；按发帖时间筛选、按post_id去重，只有约定的8个字段。 |
| 原始数据与断点 | 网站返回的完整分页响应，包含更多原始字段和分页编号；用于溯源核查、重新整理和续采。它包含重抓页及日期边界之外的记录，条数不能直接当作最终帖子数。 |
| 采集报告 | 每只股票的记录数、完成状态、实际最早/最晚发帖时间、分页情况、校验结果及数据文件SHA-256摘要；另有全部10只股票汇总。 |
| 采集脚本 | 每只股票的采集/续采程序，已经适配整理后的文件路径。 |
| 说明文档 | 每只股票的原始采集说明，包括数据来源、字段含义与采集口径。 |

## 八个字段

| 字段 | 含义 |
|---|---|
| post_id | 网站帖子的唯一编号，用于去重。 |
| stock | 本次采集的股票代码，字符串，保留002074等代码的前导零。 |
| time | 原始发帖时间，YYYY-MM-DD HH:MM:SS，北京时间。 |
| title | 帖子标题。 |
| reads | 抓取时的浏览量。 |
| comments | 抓取时的评论数量。该文件不包含评论正文。 |
| post_type | 网站原始帖子类型数字，未统一改成0。 |
| bar_code | 采集目标股吧代码，与stock相同。跨吧转载帖的原始来源股吧代码保留在raw_pages中的stockbar_code。 |

这里采集的是帖子标题与计数，不是帖子正文或评论正文。浏览量和评论数是各条记录被抓取时的快照。网站删除、隐藏或不公开的内容无法取得；列表在采集期间会变化，无法视为固定时刻的完整历史快照。

## 关于脚本和断点

脚本按股票代码对应数据及原始分页，路径以guba目录为根目录计算。续采时需要保留对应的raw_pages文件。脚本中的START、END仍是这次365天区间；直接运行不会自动变成最新365天。采集依赖互联网和Python 3.11或更新版本。脚本路径已检查语法和目录引用，本次整理没有启动采集。

赛力斯原来的`crawl_guba.py`、`采集报告.json`、`说明.txt`已分别改名为带601127的名称，便于识别。全部已有业务文件保留；只是移动归档、修正脚本路径并补充说明。隐藏文件`.DS_Store`是macOS访达的显示设置缓存，与采集数据无关。
